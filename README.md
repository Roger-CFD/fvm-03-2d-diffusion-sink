- Objective: This project solves the 2D Steady Heat-Conduction Problem with a Sink. 
- Methodology: Finite volume method with the Central Differencing Scheme (CDS) for spatial discretization.
- Implementation:Two standalone Python code versions are provided: (1) with the sink term and (2) without the sink term.
   .....Each version is self-contained and includes everything required for execution, with no separate parameter files or solver files needed.
- Results: Four plots and three tables are provided, including one table comparing the simulation results with and without the sink term. The source transitions into a sink at (T = 300) and exhibits pronounced antisymmetric behavior about the critical point, (T = 300).
